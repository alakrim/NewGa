# Bannerfall in one page

- **What:** online co-op/PvP **Frontline** (default mode): one horizontal lane, 2v2 (bots fill seats), Stick-War loop (mine gold → build → train army → push → raze enemy keep) + each player directly controls one of **20 data-driven heroes** (passive + Q/W/E/R, 60% dmg vs army). Older 5v5 MOBA/TD mode (waves, 3 banners shield the core, towers, items, camps, boss, day/night) still in the sim.
- **Economy:** per-player gold/miners/army/pop (16 → 40 via ≤3 Houses); passive 3 g/s, miner trips (15 g, safe veins + rich contested middle veins that unload at held banners; miners flee danger), Markets, 3 lane banners (Dawn/Heart/Dusk) pay per second + 150 on capture, kills pay 20% of unit cost / 200 per hero (level-scaled), ×1.5 for the side behind on army. **Sudden Death** at 12:00 crumbles both keeps and ramps income, so matches end by ~20 min.
- **Base & army:** 7 plots per player: Barracks, Archery Range, Arcane Sanctum, Giant Pit, House, Mine Shaft, Market, Forge (dmg/armor research), Watchtower. Units: Miner, Swordsman, Archer, Shieldbearer, Assassin, Battlemage, Healer, Giant. Stances: Garrison (keep fires faster, capped at 12 units), Defend, Hold line (rally), Follow (army forms up behind your hero), Attack; auto formations (heavies → ranged → casters → healers). Bots have 3 build personalities.
- **Tech:** TypeScript monorepo. `src/shared` = pure deterministic 20 Hz sim (seeded RNG → replays are seed + inputs), content as data (abilities = Effect trees run by `sim/effects.ts`), A* nav, bots. `src/server` = Node `ws`, authoritative, rooms/codes/reconnect, **server-side fog** (snapshots filtered per team). Clients send intents only. Tests: `npm test` (headless bot matches, ability smoke, server, Frontline mechanics), content validator, hero balance harness, Frontline match harness (`tools/frontline-balance.ts`).
- **Clients:** **Godot 4.7** (Mobile renderer, landscape, touch) is the main client: HUD, menus, lobby, hero gallery, build panel, end screen; `game.gd` maps the HUD's 2D px space (32 px/unit) onto a 3D camera rig (fixed 52° pitch). Old Three.js + KayKit web client still works against the same server.
- **Look (current):** **HD-2D**: Tiny Swords pixel sprites (Pixel Frog; Free Pack fetched, not redistributable) in a lit 3D world, KayKit CC0 buildings, golden-hour sun + shadows, bloom, tilt-shift DoF, split-tone grade, light shafts, fireflies.
- **Look (experiment, `godot/paintover/`):** AI paint-over pipeline. Ortho camera at the fixed pitch → one painting fits every pan/zoom. Block map after chosen concept "B: Autumn Siege" → Seedream 5.0 Flash layout pass + Muse Image refine (OpenRouter, ~$0.03/tile) → stitched panorama (two halves under 4096 px) projected on blocks; a depth variant (Depth Anything V2 → height field) for the west end; painted keep + 8 buildings on camera-facing quads with team-colour swap. Gaps: ~22 px/unit softness up close, flat trenches, only west end has depth, pixel-art units vs painterly ground style clash (review verdict: keep HD-2D as the main look, paint-over as a future map skin; see `docs/REVIEW.md`).
- **Code style:** small focused files, data tables over per-entity code, doc comments explaining *why*, Godot scripts as `preload`ed modules + autoloads (`Net`, `Sprites`), shared data mirrored to GDScript via `tools/gen-godot-data.ts`; headless visual tests (`hd2d.tscn`, `vtest.tscn`, `--uitest`) save screenshots.
- **Open gaps:** never run on a real phone, no Android/iOS export presets; heroes reuse unit bodies; ability VFX are basic; miners clutter the lower screen; damage numbers clutter fights; no music; accessibility (colour-only teams). Ideas backlog: unit possession, gold spells, unit abilities, siege/catapult, 3v3/4v4, Horde co-op.
